Privacy Policy

Quiet Desk Calendar Helper (“the app”) is a personal tool used only by its owner.

Data the app accesses

With the owner's permission, the app uses the Google Calendar API scope https://www.googleapis.com/auth/calendar.events to read, create, and delete events in the owner's primary calendar.

How the data is used

  • Calendar data is used only to answer the owner's own requests (for example, “What is on my schedule today?”).
  • Events are created or deleted only after the owner approves each action.

Storage

  • The app runs on the owner's own computer. There is no server operated for the app.
  • The sign-in token is stored only on that computer, in a file readable only by the owner.
  • A local log of created and deleted events (time, action, start time, event ID, title) is kept on that computer. Event descriptions are not logged.

Sharing

The app does not sell, share, or transfer Google user data to third parties, and does not use it for advertising. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Note: the owner's AI assistant may process calendar content to answer the owner's requests, under the owner's own account with the AI service the owner uses.

Revoking access

Access can be removed at any time from the Google Account page “Third-party apps & services” (myaccount.google.com/connections).

Contact

Questions can be raised through the issue tracker of the GitHub repository that hosts this page.
