Privacy Policy

Quiet Desk Helper (“the app”) is a personal tool used only by its owner.

Data the app accesses

With the owner's permission, the app uses these Google API scopes:

  • https://www.googleapis.com/auth/calendar.events, to read, create, and delete events in the owner's primary calendar.
  • https://www.googleapis.com/auth/gmail.readonly, to list and read the owner's Gmail messages from the last 31 days. The app cannot send or change email.

How the data is used

  • Calendar and email data is used only to answer the owner's own requests (for example, “What is on my schedule today?”) and to prepare the owner's daily summary.
  • Events are created or deleted only after the owner approves each action.
  • Email attachments are not read. A check on the owner's computer withholds message bodies that appear to contain highly sensitive information. This check is not perfect, and subjects and senders are not withheld by it.

Storage

  • The app runs on the owner's own computer. There is no server operated for the app.
  • The sign-in tokens are stored only on that computer, in files readable only by the owner.
  • A local log of created and deleted events (time, action, start time, event ID, title) is kept on that computer. Event descriptions are not logged.
  • The app does not write email content to its own logs. The AI assistant's conversation history and logs, kept on the same computer, may contain calendar or email content it has handled.

Sharing

The app does not sell Google user data and does not use it for advertising. To answer the owner's requests, the owner's AI assistant sends the calendar and email content it handles to the AI service the owner uses, under the owner's own account. That service's terms and the owner's account settings apply to this content. The app does not send Google user data anywhere else.

The app has not been reviewed or verified by Google.

Revoking access

Access can be removed at any time from the Google Account page “Third-party apps & services” (myaccount.google.com/connections). Removing the app stops its access to both Google Calendar and Gmail.

Contact

Questions can be raised through the issue tracker of the GitHub repository that hosts this page.
